# Quick-Insert-Edit

크랙에서 **메시지 수정/저장 단축키**와 **상용구 단축키를 이용한 빠른 입력**을 지원하는 Tampermonkey 스크립트입니다.

## 📥 설치

**[크랙 확프 설치하기](https://raw.githubusercontent.com/yyb02006/Quick-Insert-Edit/refs/heads/main/Quick%20Insert%20%26%20Edit.user.js)**

> **Tampermonkey가 설치되어 있어야 합니다.**

---

## 1. ✏️ 메시지 수정 / 저장 단축키

메시지를 클릭하면 아래와 같이 현재 선택된 메시지의 **메뉴 버튼에 파란색 인디케이터가 표시**됩니다.

### 단축키

| 단축키        | 기능           |
| ---------- | ------------ |
| `Ctrl + Q` | 수정 창 열기 / 닫기 |
| `Ctrl + S` | 수정 내용 저장     |

## 2. ⚡ 상용구 단축키 추가 및 사용

자주 사용하는 문구와 단축키를 직접 등록하여 빠르게 입력할 수 있습니다.

<img width="649" height="283" alt="단축키인풋" src="https://github.com/user-attachments/assets/d8b34012-d020-49e4-a034-e7c918386040" />

내용과 원하는 키를 입력한 뒤 **추가**하면 단축키가 생성됩니다.

### 사용 방법

등록한 단축키를 다음과 같이 입력합니다.

```text
Ctrl + Shift + [지정한 키]
```

예를 들어 `A` 키에 `크랙 상용구 1`을 등록했다면:

```text
Ctrl + Shift + A
```

을 채팅창이 존재하는 화면 내에서 누르거나, 채팅창 커서(캐럿) 위치를 클릭한 상태라면 커서 위치에 `크랙 사용구 1`을 빠르게 삽입할 수 있습니다.

## ⚠️ 주의사항

### 크랙에서 이미 사용 중인 단축키

일부 단축키는 크랙에서 기본 기능으로 사용되고 있기 때문에 상용구 단축키로 사용할 수 없습니다.

예를 들어:

* `Ctrl + Shift + E` — 상황 추가하기 (`**`)
* `Ctrl + Shift + S` — 대화 내역 열기/닫기
* `Ctrl + Shift + U` — 요약 메모리 열기/닫기

따라서 **크랙에서 이미 사용 중인 단축키는 등록해도 정상적으로 작동하지 않을 수 있습니다.**

### 브라우저 기본 단축키와의 충돌

`Ctrl + Shift + R`과 같이 **브라우저의 기본 동작과 겹치는 단축키**도 단축키로 추가하여 사용할 수 있습니다.

이 경우 해당 단축키를 스크립트에 등록하면 **크랙 서비스 내에서는 브라우저의 기본 동작 대신 등록한 상용구 기능이 우선적으로 작동합니다.**

예:

```text
Ctrl + Shift + R
↓
브라우저의 캐시 무효화 새로고침 대신
↓
등록한 상용구 삽입
```

> 단축키는 가능한 한 **크랙이나 브라우저에서 기본적으로 사용하지 않는 조합**을 우선 사용하는 것을 권장합니다.
